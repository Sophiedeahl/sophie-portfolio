ABOUT ME PROJECTS

Root Hunt

Game Design & Development Houdini · Unreal Engine

Root Hunt began with a series of hand-drawn creatures and grew into a short, immersive game set in a magical forest. Players explore the environment, searching for hidden creatures before time runs out.

I developed the project from initial sketches to a playable game, using Houdini for 3D modelling and world-building and teaching myself visual programming with Blueprints in Unreal Engine. I really enjoyed experimenting with unfamiliar software and figuring things out along the way. It was a fun, hands-on project that showed me how quickly I can learn new tools and techniques when I'm excited about an idea.
